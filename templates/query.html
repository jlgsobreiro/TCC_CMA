📖 Guia de Referência da DSL Declarativa (Como funciona a junção poliglota?)

A DSL permite unir dados de bancos relacionais (MySQL), orientados a documentos (MongoDB) e chave-valor (Redis) em uma única consulta estruturada em árvore:

Propriedade Tipo Descrição / Exemplos
service String Tipo do banco: mysql, mongodb ou redis
database String Nome do banco: cms, sms, fnms, oms, fms, 0
schema String Tabela MySQL ou Coleção MongoDB (clientes, pedidos, etc.)
alias String Apelido da consulta pai para amarração de chave estrangeira em consultas filhas
filter Objeto Condição de busca. Pode ser valor literal {"id": "1"} ou referência do pai {"cliente_id": {"cliente": "id"}}
on_result Objeto / Array Subconsulta executada para cada registro do pai, anexando os dados aninhados
